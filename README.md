# 100 Days of Embedded Systems: My 100-Project Journey

This repository logs my personal challenge to build 100 hardware and embedded systems projects over 100 days climbing from fundamental register level and library-free C++ on Arduino to advanced ESP32 networking, RTOS, and portfolio capstones.

---

##  The Goal
To build a hands on, practical engineering portfolio. Every day represents one self contained project (2–4 hours) that ends with working code, hardware execution, and clear documentation.

---

##  Personal Rules of Engagement

- **Explain Every Line (AI Policy):** AI is used as a learning accelerator to unblock, never to auto generate without full understanding. I must be able to explain every single line of code before it gets committed.
- **Documentation First:** Code without context is incomplete. Every project lives in its own folder with a dedicated README explaining what was built, how it works, what broke, and what was learned.
- **No Resetting:** If a day is missed, I do not restart from Day 1. I complete a half size project next and keep moving forward.
- **Python to C++ Bridge:** Starting on Day 16, projects tagged `Bridge` bridge high level Python concepts to low level C++.
- **Sustainable Pacing:** One rest day is taken every two weeks to prevent burnout and ensure long term consistency over the full 100 days.

---

##  The 100 Day Roadmap

- **Phase 1 (Days 1–15):** Bare Metal & Fundamental Drivers (No Libraries)
- **Phase 2 (Days 16–30):** Python to C++ Bridge & Sensor Integration
- **Phase 3 (Days 31–45):** Wireless Networking & ESP32 IoT
- **Phase 4 (Days 46–60):** Display Interfaces & Embedded Graphics
- **Phase 5 (Days 61–75):** Low Power Modes, FreeRTOS & Advanced C++
- **Phase 6 (Days 76–85):** Hardware Testing & PCB Design
- **Phase 7 (Days 86–100):** Portfolio Capstones
